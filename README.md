# Data Analytics with AI: practice files

Practice files for the ebook *Data Analytics with AI: Learn Data Skills from Zero and Earn Online* by Shaista Sabir.

- `data/sunrise_corner_store_sales.csv` is a clean sales sheet used in Chapter 4.
- `data/sunrise_corner_store_sales_messy.csv` is a messy version used in Chapter 5.

All shop names and numbers are invented. Nothing here describes a real business.
