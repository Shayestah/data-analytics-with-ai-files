How to use a file

  1. Get the fileChoose Download file. If your browser opens it instead, right-click the button and choose Save link as. You can also choose Copy as text and paste it into a new text file ending in .csv.
  2. Open it in a sheetIn Google Sheets, choose File, then Import, then Upload. In Excel, open the file directly.
  3. Work on a copyKeep the original untouched. Rename your copy before you change anything.

The English edition uses Sunrise Corner Store and US dollars. Files for the Urdu edition will be added here when that edition is ready.
